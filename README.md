# 传讯 Next：好友聊天框架预览

独立于 `shikitest/shiki-message-test` 的本地优先、Non-AI 聊天模拟预览。

## 来源与保护边界

- 来源：`shiki-message` 工作区的 `ime-development`。
- 来源提交：`93a06c19b4969e1a82d96f854ece8d583da8137d`。
- 复制时没有已跟踪文件的未提交改动；未跟踪的 `outputs/` 没有复制或修改。
- 原仓库、原分支和原 GitHub Pages 配置不变。
- 新站数据库：`ShikiMessageNextV1 / chat_data`。
- 新站应用键：`SHIKI_NEXT_`；浏览器同步存储外层命名空间：`SHIKI_NEXT_V1:`。
- Service Worker 仅控制新项目路径，通知点击仅聚焦新项目客户端。
- 不自动读取或迁移旧站数据库、同步存储或缓存。

## 本阶段

- 聊天 / 好友 / 更多 / 设置四个入口。
- 好友稳定 ID、独立字卡、压缩头像、独立回复概率。
- 好友单聊去重，群聊引用好友 ID 与好友字卡。
- 复用原消息发送、渲染和搜索；预览版自动回复仅使用好友字卡。
- 网站设置与会话分离，草稿按会话保存。
- 删除好友保留历史身份、停止发言；删除聊天不删除好友。
- 新版轻量备份有格式验证、恢复确认及失败回滚日志。

## 明确限制

- 切换不同会话仍采用保存后页面刷新边界；不是完整的无刷新、多会话运行系统。
- 主动发送调度关闭；全会话独立随机运行、连续消息合并等在后续实现。
- 活动邀请和共同观影已暂时关闭，等待好友身份适配；没有真实多人同步。
- 远程翻译代理默认留空，不使用旧项目服务器。
- 旧备份导入尚未支持；不要通过旧恢复界面直接导入。
- 轻量备份包含文本消息、好友字卡和关系、草稿与基础设置；不含头像、背景、媒体、音乐、活动记录和自定义 CSS。媒体消息保留文字占位。导入上限 10MB，恢复替换新版数据。
- 本阶段不进行长时间后台、大数据或全方位压力测试，不能保证真实手机无闪退。
- 保活音频仅辅助运行，不承诺锁屏、退出网站后持续执行。
